Patrón de Arquitectura PWA

Maquetado del App Shell

El App Shell es el conjunto mínimo de HTML, CSS y JavaScript que da vida a la interfaz de usuario. Se almacena en la caché del Service Worker para renderizarse de forma instantánea y confiable en aperturas consecutivas y sin conexión a internet, mientras el contenido dinámico se inyecta en el contenedor principal.

Guía de Comprobación en Chrome DevTools al Simular la Instalación

Sigue estos pasos dentro de Google Chrome para certificar la Splash Screen:

1

Abrir Chrome DevTools

Presiona F12 o Ctrl + Shift + I (en Mac: Cmd + Option + I).

2

Acceder al Panel "Application"

En la barra superior de DevTools, selecciona la pestaña Application (o Aplicación). Si no es visible, haz clic en el selector >>.

3

Inspeccionar la Sección "Manifest"

En el árbol de la izquierda, haz clic en Manifest. Verifica que Chrome muestre:

  • Identity: Name ("NovaFlow App Shell & Splash") y Short Name ("NovaFlow").
  • Presentation: Display ("standalone"), Orientation ("portrait-primary").
  • Colors: Theme color (#0f172a) y Background color (#0b0f19).
  • Icons: Vista previa de los iconos de 192x192 y 512x512 con sus máscaras.
4

Simular la Instalación mediante DevTools

En la parte superior del panel Manifest de DevTools, localiza el enlace o botón Install (o "Simulate install").

Tip de Verificación: Al hacer clic en Install, Chrome genera el banner nativo de instalación. Tras aceptar, la aplicación se abrirá en su ventana independiente standalone.
5

Emular Dispositivo Móvil para Visualizar la Splash Screen

Presiona Ctrl + Shift + M para activar la barra de emulación de dispositivos (ej. Pixel 7 / Samsung Galaxy). En DevTools, Chrome genera automáticamente la maqueta de la Splash Screen a partir del manifest.json.
